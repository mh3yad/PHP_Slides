# بلوبرنت العرض — نسخة الملفات المنفصلة

## الهيكل
- `index.html` — بوابة المحاضرات الرئيسية (Dashboard) تتيح الوصول لكافة المحاضرات.
- `lectures/lecture-01/` — المحاضرة الأولى (30 شريحة): الأساسيات، المتغيرات، والأخطاء الشائعة.
- `lectures/lecture-02/` — المحاضرة الثانية (26 شريحة): المعاملات الحسابية، المقارنة، والعمليات المنطقية مع التمارين.
- `lectures/lecture-03/` — المحاضرة الثالثة (22 شريحة): الجمل الشرطية (if/else/switch/match) والـ Ternary و Null Coalescing.
- `lectures/lecture-04/` — المحاضرة الرابعة (22 شريحة): حلقات التكرار (while, do-while, for, foreach) و break/continue.
- `lectures/lecture-05/` — المحاضرة الخامسة (29 شريحة): الـ Arrays في PHP (Indexed, Associative, Multidimensional) والدوال الأساسية الـ 10: المعالجة (push, pop, merge, unset)، البحث والتحقق (in_array, array_key_exists, count)، والـ Sort (sort, asort, ksort).
- `lectures/lecture-06/` — المحاضرة السادسة (28 شريحة): الدوال في PHP، المعاملات، return، تصريح الأنواع، القيم الافتراضية، النطاقات (global/static)، الدوال المجهولة (fn) والتمارين.
- `lectures/lecture-07/` — المحاضرة السابعة (34 شريحة): التعامل مع نماذج HTML في PHP، مقارنة GET و POST، المصفوفات الفائقة ($_POST, $_GET, $_SERVER)، والتحقق والتعقيم الأمني (XSS و SQLi) مع 3 واجبات عملية.
- `lectures/lecture-08/` — المحاضرة الثامنة (26 شريحة): معالجة النصوص (trim, explode, implode, str_replace)، نظام الملفات والتدفقات (fopen/fread/fwrite, file_get/put_contents, flock, CSV)، وتبادل وتخزين بيانات JSON مع 3 واجبات عملية.
- `lectures/lecture-09/` — المحاضرة التاسعة (29 شريحة): إدارة الحالة (State Management): الكوكيز (setcookie, $_COOKIE, HttpOnly)، الجلسات (session_start, $_SESSION, session_destroy)، حماية Session Fixation بـ session_regenerate_id، وبناء أنظمة تسجيل الدخول وسلة المشتريات ورسائل Flash مع 3 واجبات عملية.
- `assets/logo.jpg` — شعار لوغاريتم المستخدم في بوابة المحاضرات والشرائح.

## التعديل
- لتعديل أي شريحة، افتح ملفها مباشرة داخل مجلد المحاضرة المعنية (`lectures/lecture-XX/`).

## المعاينة
افتح `index.html` في المتصفح مباشرة للوصول إلى بوابة المحاضرات والتنقل بينها.
