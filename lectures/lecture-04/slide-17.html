تطبيق شامل · مثال 2

اجمع الأرقام الزوجية من 1 لحد 10

بنفحص لو $i % 2 == 0 بنضيف القيمة لمتغيّر $sum، وبعد الحلقة بنطبع الناتج.

السؤال

استخدم for من 1 إلى 10، واجمع الأرقام الزوجية فقط في متغيّر sum.

sum-even.php 
$sum = 0;
for ($i = 1; $i <= 10; $i++) {
    if ($i % 2 == 0) {
        $sum += $i;
    }
}
echo $sum;
