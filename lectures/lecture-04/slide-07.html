حلقة for

حلقة for أنسب اختيار لما نكون عارفين عدد التكرارات مقدمًا. بتجمع التهيئة والشرط والتحديث في سطر واحد.

  • بناء الجملة: for (تهيئة; شرط; تحديث) { ... }
  • التهيئة (init) بتتنفذ مرة واحدة بس في البداية
  • التحديث (increment/decrement) بيحصل بعد كل تكرار
  • ممكن نستخدم حلقات متداخلة (nested loops) جوه بعض
for.php 
for ($i = 1; $i <= 5; $i++) {
    echo $i . " ";
}
