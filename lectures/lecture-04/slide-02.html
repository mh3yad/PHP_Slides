حلقة while

حلقة while بتنفذ الكود اللي جواها طول ما الشرط بتاعها لسه true. الشرط بيتفحص قبل أي تنفيذ — يعني لو كان false من الأول، الكود مش هينفذ ولا مرة.

  • بناء الجملة: while (الشرط) { ... }
  • الشرط بيتفحص قبل كل تكرار
  • لازم نستخدم عداد (counter) وإلا الحلقة هتفضل شغالة (infinite loop)
  • مثالية للحالات اللي مش عارفين عدد التكرارات مقدمًا
while.php 
$i = 1;
while ($i <= 5) {
    echo $i;
    $i++;
}
