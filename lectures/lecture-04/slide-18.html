تطبيق شامل · مثال 3

أول رقم يقبل القسمة على 7

حلقة while (true) بتفضل شغالة لحد ما نلاقي رقم بيقبل القسمة على 7، وبعدين بنطبع رسالة ونوقف بـ break.

السؤال

ابحث عن أول رقم يقبل القسمة على 7 باستخدام while و break.

divisible-by-7.php 
$i = 1;
while (true) {
    if ($i % 7 == 0) {
        echo "$i is divisible by 7";
        break;
    }
    $i++;
}
localhost/divisible-by-7.php
7 is divisible by 7
