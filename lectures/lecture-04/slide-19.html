حاسبة درجات الطلاب

عندنا مصفوفة درجات [85, 92, 45, 78, 60]. المطلوب: نمرّ عليها بـ foreach، نتخطى أي درجة أقل من 50 (بـ continue)، نجمع الدرجات الناجحة، وفي الآخر نطبع المتوسط.

grade-calculator.php 
$grades = [85, 92, 45, 78, 60];
$sum = 0;
$count = 0;

foreach ($grades as $grade) {
    if ($grade < 50) {
        continue;
    }
    $sum += $grade;
    $count++;
}

echo "Average: " . ($sum / $count);
localhost/grade-calculator.php
