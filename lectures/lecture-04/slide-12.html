مثال 2: مصفوفة associative

بنمرّ على مصفوفة فيها مفاتيح وقيم ["John" => 25, "Jane" => 30] ونطبع جملة كاملة لكل عنصر.

foreach-assoc.php 
$ages = ["John" => 25, "Jane" => 30];
foreach ($ages as $name => $age) {
    echo "$name is $age years old\n";
}
  • أخطاء شائعة:
  • استخدام = بدل => في صيغة key-value
  • محاولة تعديل قيم المصفوفة من غير مرجع &$value
