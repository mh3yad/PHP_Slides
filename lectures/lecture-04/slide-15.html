مثال: continue

نفس الحلقة، بس دلوقتي بنستخدم continue عشان نتخطى الرقم 5 بس ونكمل الباقي.

continue.php 
for ($i = 1; $i <= 10; $i++) {
    if ($i == 5) {
        continue;
    }
    echo $i . " ";
}
// الناتج: 1 2 3 4 6 7 8 9 10
  • أخطاء شائعة:
  • استخدام break بدل continue ← بيوقف الحلقة بدل ما يتخطى عنصر
  • مش عارفين إن break 2 بيوقف حلقتين متداخلتين مع بعض
