حلقة foreach

حلقة foreach اتصممت خصيصًا للمرور على عناصر المصفوفات (arrays) — مش محتاجين عداد ولا نعرف طول المصفوفة.

  • بناء الجملة: foreach ($array as $value) { ... }
  • لو المصفوفة associative: foreach ($array as $key => $value)
  • ممكن نعدّل القيم مباشرة بالمرجع: as &$value
foreach.php 
$fruits = ["apple", "banana", "orange"];
foreach ($fruits as $fruit) {
    echo $fruit . " ";
}
