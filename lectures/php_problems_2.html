⁧عندك 5 أسامي. خزّنهم في array واطبعهم كلهم واحد تحت التاني⁩

⁧الفكرة⁩

⁧الـ foreach بتعدّي على كل عنصر في الـ array لوحده، فمش محتاجين نعرف عددهم ولا نستخدم index⁩

⁧خطوات الحل⁩

1

⁧اعمل array اسمها ⁦$names⁩ وحط فيها الـ 5 أسامي⁩

2

⁧ابدأ الـ foreach بالشكل ده: ⁦foreach ($names as $name)⁩⁩

3

⁧في كل لفة الاسم الحالي بيتحط في المتغير ⁦$name⁩⁩

4

⁧اطبع ⁦$name⁩ وبعده ⁦<br>⁩ عشان كل اسم ينزل في سطر جديد⁩

⁧المسألة 2 من 5⁩

⁧حصالة أحمد بـ while و ternary⁩

⁧المطلوب⁩

⁧أحمد عايز يشتري سماعة بـ 300 جنيه وبيوفر 50 جنيه كل أسبوع. اطبع رصيد الحصالة كل أسبوع لحد ما يوصل للمبلغ⁩

⁧الفكرة⁩

⁧الـ while بتكرر طول ما الرصيد أقل من الهدف، والـ ternary بتختار الرسالة: لسه بيوفر ولا الهدف اتحقق⁩

⁧هنستخدم⁩

while

? :

+=

⁧مثال على الناتج⁩

Week 1: 50 EGP - Keep saving
Week 2: 100 EGP - Keep saving
Week 3: 150 EGP - Keep saving
Week 4: 200 EGP - Keep saving
Week 5: 250 EGP - Keep saving
Week 6: 300 EGP - Goal reached!

⁧المسألة 2 من 5⁩

⁧خطوات الحل⁩

1

⁧جهّز المتغيرات: ⁦$goal = 300⁩ و ⁦$weekly = 50⁩ و ⁦$saved = 0⁩ و ⁦$week = 0⁩⁩

2

⁧الـ while بتكرر طول ما ⁦$saved < $goal⁩⁩

3

⁧في كل لفة زوّد رقم الأسبوع ⁦$week++⁩ وزوّد الرصيد ⁦$saved += $weekly⁩⁩

4

⁧الـ ternary بتختار الرسالة: لو ⁦$saved >= $goal⁩ تطلع ⁦Goal reached!⁩ وإلا تطلع ⁦Keep saving⁩⁩

5

⁧اطبع الأسبوع والرصيد والرسالة، وبعدها ⁦<br>⁩ للسطر الجديد⁩

⁧المسألة 2 من 5⁩

⁧الحل: الكود كامل⁩

savings.php

<?php
$goal = 300; // headphones price
$weekly = 50; // saved every week
$saved = 0;
$week = 0;

while ($saved < $goal) {
    $week++;
    $saved += $weekly;

    $status = ($saved >= $goal) ? "Goal reached!" : "Keep saving";

    echo "Week $week: $saved EGP - $status<br>";
}

⁧المسألة 3 من 5⁩

⁧من function لـ arrow function⁩

⁧المطلوب⁩

⁧اكتب function بتاخد سعر منتج وترجّع السعر بعد ضريبة 14%. وبعدين اكتبها تاني كـ arrow function بنفس النتيجة⁩

⁧الفكرة⁩

⁧الـ arrow function (fn) نسخة مختصرة من الـ function، مناسبة للدوال اللي جواها تعبير واحد بس، وموجودة من PHP 7.4⁩

⁧هنستخدم⁩

function

fn

=>

⁧مثال على الناتج⁩

114
285

⁧الدالة العادية والـ arrow function بيطبعوا نفس الأرقام⁩

⁧المسألة 3 من 5⁩

⁧خطوات الحل⁩

1

⁧اكتب الدالة العادية: ⁦function addTax($price)⁩⁩

2

⁧جواها ⁦return $price * 1.14⁩ عشان تضيف ضريبة 14%⁩

3

⁧جرّبها بسعرين: ⁦addTax(100)⁩ و ⁦addTax(250)⁩⁩

4

⁧حوّلها: اكتب ⁦$addTax = fn($price) =>⁩ وبعدها التعبير مباشرة من غير return ولا أقواس ⁦{}⁩⁩

5

⁧ناديها بالمتغير ⁦$addTax(100)⁩ والناتج نفس ناتج الدالة العادية⁩

⁧المسألة 3 من 5⁩

⁧الحل: الكود كامل⁩

tax.php

⁧الـ function العادية⁩

<?php
function addTax($price) {
    return $price * 1.14;
}

echo addTax(100) . "<br>";
echo addTax(250) . "<br>";

⁧الـ arrow function⁩

<?php
$addTax = fn($price) => $price * 1.14;

echo $addTax(100) . "<br>";
echo $addTax(250) . "<br>";

⁧المسألة 4 من 5⁩

⁧نظام Login بـ POST⁩

⁧المطلوب⁩

⁧اعمل فورم فيه Email و Password. لو البيانات صح اعرض في صفحة جديدة رسالة النجاح، وإلا اعرض رسالة الخطأ⁩

⁧الفكرة⁩

⁧الفورم بيبعت البيانات بـ POST، والصفحة الجديدة بتقارنها بالبيانات الصح⁩

⁧البيانات الصح⁩

Email: admin@gmail.com
Password: 12345678@AA

⁧مثال على الناتج في الصفحة الجديدة⁩

⁧لو البيانات صح⁩

Logged in successfully

⁧لو أي حاجة غلط⁩

Wrong credentials

⁧المسألة 4 من 5⁩

⁧خطوات الحل⁩

1

⁧اعمل ⁦login.php⁩ فيه فورم بخانتين: ⁦email⁩ و ⁦password⁩⁩

2

⁧حط في الفورم ⁦method="POST"⁩ و ⁦action="result.php"⁩⁩

3

⁧في ⁦result.php⁩ اقرا القيم المبعوتة من ⁦$_POST⁩⁩

4

⁧قارن الإيميل والباسورد بالقيم الصح باستخدام ⁦&&⁩⁩

5

⁧لو الاتنين صح اطبع ⁦Logged in successfully⁩ وإلا اطبع ⁦Wrong credentials⁩⁩

⁧المسألة 4 من 5⁩

⁧الحل: الكود (ملف 1 من 2)⁩

⁧نظام Register وصفحة التأكيد⁩

⁧المطلوب⁩

⁧فورم تسجيل: الاسم، الإيميل، تاريخ الميلاد، الباسورد وإعادته. بعد ما يخلص يتحوّل لصفحة registered وتتطبع بياناته بـ for loop⁩

⁧الفكرة⁩

⁧الباسورد لازم يساوي إعادته. والـ redirect بيبدأ request جديد، فبنحفظ البيانات في session⁩

⁧هنستخدم⁩

session

⁧مثال على الناتج في registered.php⁩

⁧لو الباسورد مش متطابق⁩

⁧المسألة 5 من 5⁩

⁧خطوات الحل⁩

1

⁧اعمل فورم في ⁦register.php⁩ فيه 5 خانات: الاسم، الإيميل، تاريخ الميلاد، الباسورد، وإعادته⁩

2

⁧لما الفورم يتبعت بـ POST قارن ⁦$_POST["password"]⁩ مع ⁦$_POST["confirm"]⁩⁩

3

⁧لو مش متطابقين اعرض رسالة الخطأ في نفس الصفحة⁩

4

⁧لو متطابقين خزّن البيانات في ⁦$_SESSION⁩ وحوّل لـ ⁦registered.php⁩ بـ ⁦header⁩⁩

5

⁧في ⁦registered.php⁩ لف على البيانات بـ ⁦for⁩ واطبع كل خانة (الباسورد بنجوم)⁩

⁧المسألة 5 من 5⁩

⁧الحل: الكود (ملف 1 من 2، الجزء الأول)⁩

register.php (1/2)

<?php
session_start();
$error = "";

if ($_SERVER["REQUEST_METHOD"] === "POST") {
    if ($_POST["password"] !== $_POST["confirm"]) {
        $error = "Passwords do not match";
    } else {
        $_SESSION["data"] = [
            "Name" => $_POST["name"],
            "Email" => $_POST["email"],
            "Date of birth" => $_POST["birth"],
            "Password" => "********",
        ];
        header("Location: registered.php");
        exit;
    }
}
?>
