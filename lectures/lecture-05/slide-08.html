مثال 2: تحديث المفاتيح وإضافة خصائص جديدة

تعديل مفتاح قائم وإضافة حقول إضافية لـ Array إعدادات حساب المستخدم:

المطلوب البرمجي

حدّث البريد الإلكتروني للمستخدم، وأضف خاصية role بقيمة admin ثم اعرض النتيجة.

user_update.php 
$user = [
    "username" => "mahmoud_99",
    "email"    => "old@test.com"
];

// تحديث البريد الإلكتروني
$user["email"] = "new_email@gmail.com";

// إضافة مفتاح الرتبة
$user["role"] = "مدير النظام";

echo "المستخدم: {$user['username']} | الرتبة: {$user['role']}";
localhost/user_update.php
