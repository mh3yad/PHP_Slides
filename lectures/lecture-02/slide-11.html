معاملات PHP الحديثة — Spaceship Operator

معامل سفينة الفضاء (<=>): المقارنة الثلاثية في سطر واحد

معامل نزل من أول PHP 7، وسموه Spaceship عشان شبه المركبة الفضائية. بيختصر 3 مقارنات في سطر واحد:

spaceship.php 
<?php

// الحالة 1: اللي على الشمال أصغر من اللي على اليمين
echo (10 <=> 20); // -1
echo "<br>";

// الحالة 2: الاتنين قد بعض بالظبط
echo (20 <=> 20); // 0
echo "<br>";

// الحالة 3: اللي على الشمال أكبر من اللي على اليمين
echo (30 <=> 20); // 1

?>
localhost/spaceship.php
-1 0 1
🚀 لما يكون $a < $b ← بيرجع -1 (عشان اللي على الشمال أصغر)
🚀 لما يكون $a == $b ← بيرجع 0 (عشان الاتنين قد بعض بالظبط)
🚀 لما يكون $a > $b ← بيرجع 1 (عشان اللي على الشمال أكبر)
