المنطق المركب — Combined Logic (Example 1)

دمج AND مع OR: المثال 1 — شروط دخول الحفلة

الشرط: الزائر بيدخل لو هو VIP أو (معاه تذكرة وسنه 18 سنة فما فوق):

party_access.php 
<?php

// بيانات الزائر (Hardcoded):
$isVIP     = false;
$hasTicket = true;
$age       = 20;

// التعبير المركب بالأقواس لحماية المنطق:
$canEnter = $isVIP || ($hasTicket && $age >= 18);

echo "هل مسموح له يدخل؟ ";
var_dump($canEnter); // bool(true)

?>
localhost/party_access.php
هل مسموح له يدخل؟ bool(true)
🔍 تعال نتتبع الكود خطوة بخطوة:
1. بنحسب اللي جوة القوس الأول: true && (20 >= 18) --> True
2. بعدين نحسب بوابة OR البرانية: false || True --> True
💡 فكرة كمان: لو الزائر $isVIP = true وعنده 12 سنة ومعاهوش تذكرة، هيدخل برضه فوراً عشان شرط الـ VIP كافي لوحده يفتصله الباب!
