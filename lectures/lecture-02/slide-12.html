مقارنة النصوص — Strings & ASCII

مقارنة الحروف والنصوص: إزاي PHP بيقارن الكلمات؟

في البرمجة، الحروف بتتقارن بأرقامها في جدول ASCII وبالترتيب الأبجدي زي القاموس:

compare_strings.php 
<?php

// 1. مقارنة الحروف بأرقام ASCII في الكمبيوتر:
// 'a' = 97 , 'b' = 98 , 'A' = 65
var_dump('a' < 'b');  // bool(true) لأن 97 < 98
var_dump('A' < 'a');  // bool(true) الحروف الكبيرة أرقامها أصغر!

// 2. مقارنة الكلمات والنصوص بالترتيب القاموسي:
var_dump("apple" < "banana"); // bool(true) عشان a قبل b
var_dump("apple" == "apple");  // bool(true) متطابقين
var_dump("PHP" === "php");    // bool(false) الكابيتال غير السمول!

?>
localhost/compare_strings.php
bool(true) bool(true) bool(true) bool(true) bool(false)
🔡 إزاي PHP بيرتب الحروف في جدول ASCII:
• الحروف الكبيرة A-Z واخدة أرقام من 65 لحد 90
• الحروف الصغيرة a-z واخدة أرقام من 97 لحد 122
• عشان كدة: 'Z' < 'a' بتطلع True لأن 90 أصغر من 97!
