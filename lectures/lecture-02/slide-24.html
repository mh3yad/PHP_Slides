حل التمرين 2: أهلية الخصم التجاري (OR Gate)

المطلوب: نطبع 1 لو السعر أكتر من 100$ أو المشتري طالب، وغير كدة نطبع 0:

exercise_02.php 
<?php

// 1. متغيرات ثابتة بتمثل السعر وحالة الطالب:
$price = 120.5;     // double
$isStudent = false; // bool

// 2. التعبير المنطقي باستخدام بوابة OR (||):
$hasDiscount = ($price > 100) || ($isStudent === true);

// 3. إخراج النتيجة كـ 1 أو 0:
echo (int)$hasDiscount . "<br>";

// 4. فحص القيمة المنطقية بـ var_dump:
var_dump($hasDiscount);

?>
localhost/exercise_02.php
1 bool(true)
🧠 فهم الحل خطوة بخطوة:
• السعر 120.5 > 100 بيطلع True
• حالة الطالب false === true بتطلع False
• ناتج بوابة OR: True || False بيطلع 1 (مستحق للخصم)
• خد بالك: لو السعر 80$ والعميل طالب، كان هياخد الخصم برضه لأن False || True بتدي 1!
