السحر البرمجي لـ (%): فحص الأعداد الزوجية والفردية

معامل باقي القسمة (%) بيعرفك هل الرقم بيقبل القسمة من غير باقي ولا لأ، وده المعيار لمعرفة الزوجي والفردي:

odd_even.php 
<?php

$num1 = 14;
$num2 = 19;

// القاعدة: أي رقم % 2 = 0 يبقى زوجي (Even)
$rem1 = $num1 % 2; // 14 / 2 = 7 والباقي 0
echo "14 % 2 = " . $rem1 . " --> زوجي (Even)<br>";

// أي رقم % 2 != 0 يبقى فردي (Odd)
$rem2 = $num2 % 2; // 19 / 2 = 9 والباقي 1
echo "19 % 2 = " . $rem2 . " --> فردي (Odd)";

?>
localhost/odd_even.php
14 % 2 = 0 --> زوجي (Even) 19 % 2 = 1 --> فردي (Odd)
✅ العدد الزوجي (Even): $number % 2 == 0 (بيقبل القسمة على 2 ومن غير باقي خالص)
⚠️ العدد الفردي (Odd): $number % 2 != 0 (دايماً بيتبقالك 1 بعد القسمة)
