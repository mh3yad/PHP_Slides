تطبيق واقعي — Real-world AND Gate

بوابة AND عملياً: موافقة (السن والمرتب)

الشرط: بيتقبل بس لو السن أكبر من 25 و المرتب أكتر من 5000 ($age > 25 && $salary > 5000):

الحالة 1: الشرطين اتحققوا مقبول (1) True
$age = 30; $salary = 7000;
(30 > 25) && (7000 > 5000) --> True && True

السن تمام والمرتب تمام، فـ القرض اتقبل على طول.

الحالة 2: السن تمام بس المرتب قليل مرفوض (0) False
$age = 30; $salary = 4000;
(30 > 25) && (4000 > 5000) --> True && False

رغم إن السن فوق 25، بس المرتب مش كافي فـ اترفض.

الحالة 3: المرتب عالي بس السن صغير مرفوض (0) False
$age = 22; $salary = 7000;
(22 > 25) && (7000 > 5000) --> False && True

المرتب ممتاز، بس شرط السن مكملش فـ اترفض فوراً.

الحالة 4: ولا شرط من الاتنين اتحقق مرفوض (0) False
$age = 20; $salary = 3000;
(20 > 25) && (3000 > 5000) --> False && False

ولا السن نافع ولا المرتب نافع، فـ النتيجة سلبية تماماً.
