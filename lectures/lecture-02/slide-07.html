كتابة كود أنظف — Assignment Operators

معاملات التعيين والإسناد المركبة: اكتب أقل وأسرع

بدل ما تقعد تكرر اسم المتغير مرتين، PHP بتديك معاملات جاهزة تعمل العملية وتحدث القيمة فوراً:

assignment.php 
<?php

$x = 10;
$x += 5;  // تعادل: $x = $x + 5; (15)
$x -= 3;  // تعادل: $x = $x - 3; (12)
$x *= 2;  // تعادل: $x = $x * 2; (24)
$x /= 4;  // تعادل: $x = $x / 4; (6)
$x %= 4;  // تعادل: $x = $x % 4; (2)

// دمج النصوص وإسنادها في سطر واحد:
$title = "PHP ";
$title .= "Course"; // $title = $title . "Course";

echo "القيمة النهائية لـ x: " . $x . "<br>";
echo "النص النهائي: " . $title;

?>
localhost/assignment.php
