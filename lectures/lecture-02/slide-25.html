حل التمرين 3: نظام التحكم في الدخول المعقد

المطلوب: الباب يفتح (1) في الطوارئ أو (معاه الكارت و عارف الرمز مع بعض)، وغير كدة 0:

exercise_03.php 
<?php

// 1. متغيرات ثابتة بتمثل الحالة:
$hasKeycard   = true;
$knowsPIN     = false;
$isEmergency  = true;

// 2. المنطق المركب مع عزل شرط الكارت والرمز بالأقواس:
$canOpenDoor = $isEmergency || ($hasKeycard && $knowsPIN);

// 3. طباعة النتيجة 1 أو 0:
echo (int)$canOpenDoor . "<br>";

// 4. فحص القيمة والنوع:
var_dump($canOpenDoor);

?>
localhost/exercise_03.php
1 bool(true)
🧠 فهم الحل خطوة بخطوة:
• حالة الطوارئ شغالة $isEmergency = true
• فحص الدخول العادي: true && false بيطلع False
• القرار النهائي لبوابة OR: true || false بيطلع 1 (الباب هيفتح فوراً!)
• في الطوارئ السيستم بيتجاوز كل الفحوصات الأمنية أوتوماتيك عشان يحمي الناس.
