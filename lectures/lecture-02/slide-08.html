مقارنة القيم — Comparison Operators

معاملات المقارنة: الأكبر والأصغر والتساوي

بنستخدمها عشان نقارن بين قيمتين، وبترجع دايماً قيمة بوليانية (صح True أو غلط False):

comparison.php 
<?php

$x = 10;
$y = 5;

// معاملات المقارنة الأساسية:
echo ($x > $y) . "<br>";  // أكبر من: 10 > 5 -> 1 (True)
echo ($x < $y) . "<br>";  // أصغر من: 10 < 5 -> فراغ (False)
echo ($x >= 10) . "<br>"; // أكبر من أو يساوي -> 1
echo ($y <= 3) . "<br>";  // أصغر من أو يساوي -> فراغ
echo ($x != $y) . "<br>"; // مش بيساوي -> 1
echo ($x <> $y);         // <> زي != بالظبط -> 1

?>
المعامل معناه المثال
> أكبر من
Greater
10 > 5 (صح True)
< أصغر من
Smaller
3 < 7 (صح True)
>= أكبر أو يساوي
GTE
10 >= 10 (صح True)
<= أصغر أو يساوي
LTE
4 <= 2 (غلط False)
!= أو <> مش بيساوي
Not Equal
5 != 8 (صح True)
