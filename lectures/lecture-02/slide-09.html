سر التعامل مع Booleans — Echo vs Var_dump

تخزين ناتج المقارنة: الفخ بين echo و var_dump!

تقدر تخزن ناتج أي مقارنة جوة متغير، بس خد بالك كويس من اللي بيحصل لما تيجي تطبعه بـ echo مقابل var_dump:

store_comparison.php 
<?php

$a = 20;
$b = 10;

// تخزين نتيجة المقارنة جوة متغير:
$isGreater = ($a > $b); // true
$isSmaller = ($a < $b); // false

// فخ echo:
echo "ناتج isGreater بـ echo: " . $isGreater . "<br>";
echo "ناتج isSmaller بـ echo: " . $isSmaller . "<br>";

// قوة var_dump اللي بتكشف الحقيقة:
var_dump($isGreater);
echo "<br>";
var_dump($isSmaller);

?>
localhost/store_comparison.php
ناتج isGreater بـ echo: 1 ناتج isSmaller بـ echo: bool(true) bool(false)
🚨 فخ بيقع فيه أغلب الناس: دالة echo بتطبع للـ true رقم 1، لكن لو false مش بتطبع أي حاجة خالص (فراغ "") ولا حتى صفر! عشان كدة لازم تعتمد على var_dump() عشان تشوف نوع وقيمة المتغير بجد.
