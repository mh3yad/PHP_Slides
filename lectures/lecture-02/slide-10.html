المقارنة الصارمة: الفرق الجوهري بين == و ===

هل الرقم 5 بيساوي النص "5"؟ في PHP الإجابة بتعتمد على المعامل اللي بتستخدمه:

strict_compare.php 
<?php

$num = 5;    // Integer
$str = "5";  // String

// 1. المقارنة السايبة (Loose ==): بتقارن القيمة بس
var_dump($num == $str);  // bool(true) خطر جداً!

// 2. المقارنة الصارمة (Strict ===): بتقارن القيمة والنوع مع بعض
var_dump($num === $str); // bool(false) أمان تام!

// ونفس الفكرة بالظبط في مش بيساوي:
var_dump($num != $str);  // bool(false)
var_dump($num !== $str); // bool(true) صارمة!

?>
