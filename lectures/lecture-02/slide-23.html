الحلول النموذجية — Exercise 1 Solution

حل التمرين 1: التحقق من السن والاشتراك (AND Gate)

المطلوب: نطبع 1 لو السن 18 سنة فما فوق و الاشتراك نشط، وغير كدة نطبع 0:

exercise_01.php 
<?php

// 1. متغيرات ثابتة بتمثل بيانات اليوزر:
$age = 20;
$hasMembership = true; // 1 يعني نشط

// 2. التعبير المنطقي باستخدام بوابة AND (&&):
$isEligible = ($age >= 18) && ($hasMembership === true);

// 3. طباعة النتيجة كرقم 1 أو 0:
echo (int)$isEligible . "<br>";

// 4. فحص القيمة والنوع بالتفصيل:
var_dump($isEligible);

?>
localhost/exercise_01.php
1 bool(true)
🧠 فهم الحل خطوة بخطوة:
• السن 20 >= 18 بيطلع True
• الاشتراك true === true بيطلع True
• ناتج بوابة AND: True && True بيطلع 1 (مقبول)
• حطينا (int) قبل المتغير عشان نطبع 0 في حالة الرفض بدل ما echo تسيبها فاضية!
