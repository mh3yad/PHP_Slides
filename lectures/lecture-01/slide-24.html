التحويل الصريح للأنواع (Type Casting)

عندما تريد أنت إجبار PHP على تحويل نوع المتغير لنوع محدد بدقة، نضع اسم النوع بين قوسين قبل القيمة المطلوبة:

casting.php 
// تحويل نص إلى رقم صحيح (int)
$input = "150";
$price = (int)$input;
var_dump($price);   // int(150)

// تحويل رقم إلى نص (string)
$score = 98;
$text = (string)$score;
var_dump($text);    // string(2) "98"

// تحويل رقم إلى Boolean (الصفر يعطي false)
$active = (bool)0;
var_dump($active);  // bool(false)
localhost/casting.php
int(150) string(2) "98" bool(false)
