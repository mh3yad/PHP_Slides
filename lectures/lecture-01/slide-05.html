أي كود PHP يُكتب داخل <?php ... ?>، وللطباعة نستخدم echo أو print. إليك الفروق الجوهرية بينهما:

index.php 
<?php

// 1. echo: أسرع وتقبل معاملات متعددة
echo "Hello", " ", "World!";

// 2. print: تأخذ معاملاً واحداً وترجع دائماً 1
print "<br>Welcome";
$res = print " PHP"; // $res = 1

?>
