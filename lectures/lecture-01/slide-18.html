فهرس المحتوى — Course Outline (الجزء 2)

محاور المحاضرة الثانية: المتغيرات والبيانات

الموضوعات التي تم شرحها وتطبيقها عمليًا في المحاضرة الثانية:

01
هيكلية الويب (Web Architecture) مسار الطلب والرد: Client ➔ Server ➔ PHP & DB ➔ Response
02
تعريف المتغيرات (Declaring Variables) حجز مساحة بالذاكرة، علامة $، ومعامل الإسناد = في PHP
03
أنواع البيانات الأساسية (Primitive Types) الأنواع الخمسة: String و Integer و Float و Boolean و Null
04
فحص البيانات بدقة عبر var_dump() معرفة نوع المتغير، طول النص، والقيمة الفعلية لتصحيح الأخطاء
05
التحويل التلقائي للأنواع (Type Juggling) مرونة PHP في تحويل الأنواع تلقائيًا حسب المعامل المستخدم
06
التحويل الصريح للأنواع (Type Casting) إجبار التحويل اليدوي باستخدام (int), (string), (bool), (float)
07
قواعد التسمية والأخطاء الشائعة قواعد Syntax، وأشهر أخطاء الـ Compile والـ Runtime وكيفية تفاديها
