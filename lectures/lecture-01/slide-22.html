فحص البيانات — var_dump()

تطبيق عملي: مخرجات var_dump()

دالة var_dump() تكشف النوع والطول والقيمة الفعلية — لا غنى عنها في معرفة أسرار المتغيرات وتصحيح الأخطاء:

types.php 
$site   = "Logharitm"; // String
$rank   = 1;           // Integer
$rating = 4.9;         // Float
$isOpen = true;        // Boolean
$promo  = null;        // Null

var_dump($site);
var_dump($rank);
var_dump($rating);
var_dump($isOpen);
var_dump($promo);
localhost/types.php
string(9) "Logharitm" int(1) float(4.9) bool(true) NULL
