تحويل arrays إلى json_encode() string

تحويل أي array أو كائن PHP إلى string مهيأ بصيغة JSON مع الحفاظ على التنسيق واللغة العربية:

  • json_encode($data, $flags): تحول array إلى string بتنسيق JSON .
encode_json.php 
$book = [
    "title"  => "تعلم PHP الحديثة",
    "author" => "لوغاريتم",
    "price"  => 120,
    "tags"   => ["برمجة", "ويب"]
];

$jsonString = json_encode($book);

echo $jsonString;
