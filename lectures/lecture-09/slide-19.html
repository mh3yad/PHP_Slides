تطبيق 2: ميزة «تذكرني» بدمج الكوكيز مع الجلسات

كيف تحتفظ بتسجيل دخول المستخدم لمدة 14 يوماً حتى بعد إغلاقه للمتصفح بالكامل:

فكرة التطبيق الاحترافية

عند تسجيل الدخول بنجاح مع اختيار «تذكرني»، نفتح جلسة فورية ونزرع كوكي باسم المستخدم مشفراً أو بمعرف دائم صالح لمدة أسبوعين.

remember_login.php 
session_start();

// 1. حفظ جلسة العمل الحالية
$_SESSION['user'] = $username;
$_SESSION['logged_in'] = true;

// 2. فحص اختيار تذكرني
if (!empty($_POST['remember'])) {
    setcookie(
        'remember_user', 
        $username, 
        time() + (86400 * 14), // أسبوعين
        '/', 
        '', 
        false, 
        true // httponly
    );
}
