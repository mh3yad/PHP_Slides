تطبيق 3: بناء سلة تسوق متكاملة بـ $_SESSION

إدارة عناصر السلة والكميات وتحديثها فورياً في جلسة الزائر عبر صفحات المتجر المختلفة:

المطلوب البرمجي

تهيئة مصفوفة $_SESSION['cart']، وإضافة منتج مع زيادة كميته إن كان موجوداً، وحساب إجمالي السلة.

cart.php 
session_start();
if (!isset($_SESSION['cart'])) {
    $_SESSION['cart'] = [];
}

// إضافة منتج بالـ ID
$id = $_GET['add'] ?? null;
if ($id) {
    if (isset($_SESSION['cart'][$id])) {
        $_SESSION['cart'][$id]['qty']++;
    } else {
        $_SESSION['cart'][$id] = ['title' => 'ماوس', 'price' => 300, 'qty' => 1];
    }
}
