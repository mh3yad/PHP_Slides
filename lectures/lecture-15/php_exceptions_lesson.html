الموضوع 1

Error Code ولا Exception؟

الـ Error هو الغلط نفسه. الـ Exception هو طريقة PHP إنها تبلّغك بالغلط ده

Error Code 🏷️
الدالة بترجع false أو -1
و انت لازم تفتكر تفحصها 😴
VS
Exception 🚨
الدالة بترمي throw غلط
مينفعش تتجاهله

مثال: تقسيم حساب المطعم 🍕

ليه الـ Exception أحسن من -1؟

bill.php
1<?php 2function splitBill($total, $people) { 3 if ($people == 0) { 4 return -1; 5 } 6 return $total / $people; 7} 8 9echo splitBill(100, 0);
Output
-1

الرقم -1 شكله عادي! 😵 محدش هيعرف إن فيه غلط. لكن لو رمينا Exception الغلط بيبان و لازم حد يمسكه

الموضوع 2

try و catch ☕

try = جرّب الكود الخطر 🧪  |  catch = لو غلط، امسكه هنا 🥅

coffee.php
1<?php 2function orderCoffee($sugar) { 3 if ($sugar > 5) { 4 throw new Exception("Too much sugar!"); 5 } 6 return "Coffee with $sugar sugar"; 7} 8 9try { 10 echo orderCoffee(2) . "\n"; 11 echo orderCoffee(9) . "\n"; 12} catch (Exception $e) { 13 echo "Sorry: " . $e->getMessage(); 14}
Output
Coffee with 2 sugar Sorry: Too much sugar!

الأوردر التاني غلط، لكن البرنامج مقفلش — راح للـ catch و كمّل ✅

الموضوع 3

throw: ارمي الغلط بنفسك 🏧

الشكل: throw new Exception("message")

atm.php
1<?php 2function withdraw($balance, $amount) { 3 if ($amount > $balance) { 4 throw new Exception("Not enough money"); 5 } 6 return $balance - $amount; 7} 8 9try { 10 echo "Start\n"; 11 withdraw(100, 500); 12 echo "Done\n"; 13} catch (Exception $e) { 14 echo "Error: " . $e->getMessage(); 15}
Output
Start Error: Not enough money

لاحظ إن "Done" مااتطبعتش! أول ما حصل throw، PHP قفزت على الـ catch على طول 🏃

الموضوع 4

نقرا تفاصيل الغلط 🎬

getMessage() الرسالة  |  getCode() رقم الغلط  |  getLine() رقم السطر

cinema.php
1<?php 2function checkAge($age) { 3 if ($age < 18) { 4 throw new Exception("Too young for this movie", 101); 5 } 6} 7 8try { 9 checkAge(15); 10} catch (Exception $e) { 11 echo $e->getMessage() . " | " . $e->getCode() . " | line " . $e->getLine(); 12}
Output
Too young for this movie | 101 | line 4

الرقم 4 هو السطر اللي فيه throw 🎯

الواجب 🏠

جرب بنفسك على الكمبيوتر 💻

● سؤال 1 (سهل 🟢): اكتب checkTicket($age) بترمي Exception برسالة "Too young" لو السن أقل من 18. استدعيها جوه try و اطبع الرسالة بـ getMessage().
● سؤال 2 (سهل 🟢): اكتب buyItem($price, $money) بترمي Exception برسالة "Not enough money" لو $money أقل من $price. جرّبها مرة بفلوس كفاية و مرة لأ.
● سؤال 3 (متوسط 🟠): عندك [2, 0, 5] وده عدد الأصحاب. اعمل foreach و استدعي splitBill(100, $n). لو $n صفر ارمي Exception بكود 100. امسكه جوه الـ loop و اطبع الرسالة و الكود، و كمّل على الرقم اللي بعده.
