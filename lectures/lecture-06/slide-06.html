مثال 1: دالة الجمع add($a, $b)

تعريف دالة تقبل معاملين وترجع حاصل جمعهما، ثم استدعاؤها وطباعة الناتج.

السؤال

عرّف دالة باسم add($a, $b) ترجع حاصل جمع a و b. استدعِ الدالة بالقيمتين 5 و 3 واطبع النتيجة في المتصفح.

add.php 
function add($a, $b) {
    return $a + $b;
}

$sum = add(5, 3);
echo $sum;
