مثال 1: دالة مضاعفة الرقم $double

إنشاء دالة مجهولة تأخذ رقماً وترجع ضعفه، وتخزينها في متغير واستدعائها.

السؤال

أنشئ دالة مجهولة تستقبل رقماً وترجع ضعفه (ضرب 2). أسندها للمتغير $double، ثم استدعِها بالرقم 5 واطبع الناتج.

double.php 
$double = function($num) {
    return $num * 2;
};

echo $double(5);

// بديل السهم في PHP 7.4+:
// $double = fn($num) => $num * 2;
