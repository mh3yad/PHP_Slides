مثال 1: استخدام الكلمة المفتاحية global $x

الوصول لمتغير عام معرف خارج الدالة باستخدام الكلمة المفتاحية global.

السؤال

عرّف المتغير $x = 10 خارج دالة. داخل دالة باسم printX()، استخدم global $x للوصول إليه واطبعه في المتصفح.

global.php 
$x = 10;

function printX() {
    global $x;
    echo $x;
}

printX();
localhost/global.php
