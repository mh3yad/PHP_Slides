مثال 2: استخدام دالة مجهولة مع array_map

استخدام دالة مجهولة كـ Callback مع array_map لتربيع عناصر الـ array [1, 2, 3].

السؤال

استخدم دالة array_map مع دالة مجهولة لحساب مربع كل رقم في الـ array [1, 2, 3] للحصول على [1, 4, 9]. اطبع الناتج بـ print_r.

array_map.php 
$nums = [1, 2, 3];

$squared = array_map(function($n) {
    return $n * $n;
}, $nums);

print_r($squared);
localhost/array_map.php
Array ( [0] => 1 [1] => 4 [2] => 9 )
