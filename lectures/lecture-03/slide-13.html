Switch

جملة Switch — بديل لسلسلة elseif الطويلة

  • switch بتقارن متغير واحد بعدة قيم محتملة.
  • كل case بينفذ لو القيمة اتطابقت، ولازم break بعده عشان يوقف التنفيذ.
  • default بتشتغل لو مفيش أي case اتطابق.
switch-basics.php 
<?php
$grade = "B";

switch ($grade) {
    case "A": echo "Excellent"; break;
    case "B": echo "Good"; break;
    case "C": echo "Average"; break;
    default: echo "Needs Improvement";
}
// Output: Good
