جملة If · صيغة الأسطر المتعددة

If بالأقواس {} — أكتر من سطر

  • لو عايز تنفذ أكتر من سطر جوه الشرط، لازم تحوطهم بأقواس {}.
  • ده بيخلي الكود أوضح، وأسهل إنك تضيفله أسطر تانية بعدين.
  • نصيحة: استخدم الأقواس دايمًا حتى لو السطر واحد — بتقلل الأخطاء.
if-block.php 
<?php
$score = 45;

if ($score < 60) {
    echo "Result: Fail\n";
    echo "You need to retake the exam.";
}
// Output:
// Result: Fail
// You need to retake the exam.
