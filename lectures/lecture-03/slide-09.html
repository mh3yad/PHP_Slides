حاسبة بسيطة باستخدام If

هنبني حاسبة بتاخد رقمين وعملية حسابية، وبتحدد الناتج المناسب باستخدام if / elseif.

calculator-if.php 
<?php
$num1 = 12;
$num2 = 4;
$operator = "*";

if ($operator == "+") $result = $num1 + $num2;
elseif ($operator == "-") $result = $num1 - $num2;
elseif ($operator == "*") $result = $num1 * $num2;
elseif ($operator == "/") $result = $num1 / $num2;
else $result = "Invalid operator";

echo $result; // Output: 48
