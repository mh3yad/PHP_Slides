جملة If · elseif

If / Elseif / Else — سلم الدرجات كامل

  • elseif بتضيفلك أكتر من احتمال، وبتتفحص بالترتيب من فوق لتحت.
  • أول شرط يتحقق هو اللي بينفذ، والباقي بيتجاهل تمامًا.
  • الترتيب مهم جدًا — لازم تبدأ بأعلى قيمة وتنزل.
grading-scale.php 
<?php
$score = 82;

if ($score >= 90) $grade = "A";
elseif ($score >= 80) $grade = "B";
elseif ($score >= 70) $grade = "C";
elseif ($score >= 60) $grade = "D";
else $grade = "F";

echo $grade; // Output: B
