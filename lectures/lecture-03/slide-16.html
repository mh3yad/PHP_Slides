Ternary — جملة If في سطر واحد

  • الصيغة: الشرط ? القيمة_لو_صح : القيمة_لو_غلط
  • مفيدة جدًا لما القرار بسيط وقيمة واحدة بس بتتغير.
  • فيه كمان صيغة مختصرة (Elvis) بتستخدم القيمة نفسها لو كانت truthy.
ternary.php 
<?php
$score = 72;

$result = ($score >= 60) ? "Pass" : "Fail";
echo $result;
// Output: Pass

// short form (Elvis operator)
$name = $studentName ?: "Guest";
