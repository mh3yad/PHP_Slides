جملة If · If متداخلة

Nested If — شرط جوه شرط

  • ممكن تحط جملة if كاملة جوه if تانية.
  • بتتحقق من شروط إضافية — بس لو الشرط الأساسي اتحقق الأول.
  • مفيدة لما القرار محتاج أكتر من خطوة تفكير.
nested-if.php 
<?php
$score = 95;
$attendance = 90; // percentage

if ($score >= 60) {
    echo "Pass\n";
    if ($score >= 90 && $attendance >= 85) {
        echo "Honors Student!";
    }
} else {
    echo "Fail";
}
// Output: Pass / Honors Student!
