جملة If · صيغة السطر الواحد

If من غير أقواس — سطر واحد بس

  • لو هينفذ من الشرط سطر واحد بس، تقدر تستغنى عن الأقواس {}.
  • الصيغة: if (الشرط) نفّذ_سطر;
  • مفيدة في الحالات البسيطة، بس لو الكود هيكبر بعدين الأفضل تستخدم الأقواس عشان الوضوح.
if-one-line.php 
<?php
$score = 85;

if ($score >= 60) echo "Pass";
// Output: Pass
