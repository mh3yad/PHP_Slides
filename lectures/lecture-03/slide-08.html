التحذير الكبير: = مقابل ==

علامة = بتستخدم للإسناد (تحط قيمة في متغير) — مش للمقارنة. لو كتبتها بالغلط جوه شرط، PHP هتحط القيمة وترجع true دايمًا.

wrong.php 
<?php
$grade = 50;

if ($grade = 90) { // WRONG!
    echo "Always runs";
}

var_dump($grade);
// $grade is now 90 -- overwritten!
right.php 
<?php
$grade = 50;

if ($grade == 90) { // correct
    echo "Only if grade is 90";
}

var_dump($grade);
// $grade is still 50 -- unchanged
الغلطة دي من أكتر الأخطاء اللي بتصيب المبتدئين — راجع شرطك كويس قبل ما تشغّل الكود.
