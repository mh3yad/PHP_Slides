Match — نسخة أحدث وأذكى من Switch

  • match بترجع قيمة مباشرة — مش محتاجة break.
  • بتقارن بالـ === (صارمة)، عكس switch اللي بيقارن بـ ==.
  • لو مفيش أي حالة اتطابقت ومفيش default، هترمي Error.
match-basics.php 
<?php
$grade = "B";

$message = match ($grade) {
    "A" => "Excellent",
    "B" => "Good",
    "C" => "Average",
    default => "Needs Improvement",
};

echo $message;
// Output: Good
